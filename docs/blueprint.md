# **App Name**: 산책 일기

## Core Features:

- 사진 촬영: 앱 내에서 직접 산책 사진을 찍을 수 있습니다.
- 위치 태깅: 산책 중인 사진에 위치 데이터를 자동으로 태그합니다. 개인 정보 보호를 위해 위치 정보 사용 여부를 설정할 수 있습니다.
- 일기 쓰기: 각 사진과 관련된 개인적인 감상, 생각, 메모를 추가합니다.
- 산책 일기 스마트 추천 도구: 생성형 AI 도구를 사용하여 일기 항목에 더 많은 세부 정보를 추가할 수 있도록 쓰기 프롬프트 제안을 제공합니다.
- 산책 기록: 산책 통계(거리, 시간, 걸음 수)를 자동으로 기록합니다.
- 사진 갤러리: 산책 사진 및 일기 항목을 갤러리에서 보고 정리합니다.
- 경로 추적: GPS 데이터와 주소의 역지오코딩을 사용하여 경로를 시각적으로 표시합니다.

## Style Guidelines:

- 배경색: 매우 밝은 회색빛 파란색(#F0F4F8)으로 깨끗하고 차분한 배경을 제공합니다.
- 주요 색상: 차분한 파란색(#779ECB)은 자연과의 평온함과 연결을 제공합니다.
- 강조 색상: 부드러운 라벤더색(#B19CD9)은 대화형 요소와 저널 프롬프트를 강조하는 데 사용되어 창의적인 느낌을 더합니다.
- 글꼴: 'Alegreya'는 인본주의적 세리프체로 우아하고 지적이며 현대적인 느낌을 줍니다.
- 카메라, 위치, 저널, 지도와 같은 다양한 기능을 나타내는 간단한 선 기반 아이콘입니다. 스타일은 평화로운 느낌을 보완합니다.
- 섹션을 명확하게 구분한 깨끗하고 미니멀한 레이아웃입니다. 사진과 텍스트에 집중할 수 있도록 여백을 사용합니다. 일기 항목 섹션은 항상 전면 중앙에 있습니다.
- 섹션 간의 부드러운 전환입니다. 갤러리를 스크롤할 때 미묘한 시차 효과를 주어 사용자에게 즐거움을 선사합니다.
